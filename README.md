# Five o'clock

A single-page graphic series built around a Big Ben tower that lives through
four phases of London time — morning, day, evening, night — and eight
minimalist city postcards, each keeping its own local time.

**Live:** https://k0teu4.github.io/5-o-clock/

**Status:** ❄️ frozen — final edition of eight postcards, sealed on September 13, 2026. No further additions planned.

## The series

01 London · 02 Tokyo · 03 Paris · 04 Istanbul
05 Moscow · 06 Rome · 07 New York · 08 Beijing

One ink pen, one typeface (Playfair Display), eight coloured papers.

## Features

- Hero poster repaints itself by real London time (morning / day / evening / night).
- Every postcard shows its city's live local time.
- Postcards fade in as you scroll into them.
- Easter egg: at exactly 17:00 London time the site stops work and brews tea.
- Print stylesheet: the collection prints as a 4×2 sheet of postcards.
- Copy-to-clipboard email button (no `mailto:`).
- Vanilla HTML + CSS + JS, hand-drawn SVG, no dependencies.

## Run locally

Just open `index.html` — no build step, no server needed.
